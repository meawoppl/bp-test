# BAV199 source notes (PDF retrieval pending)

[Nexperia datasheet](https://assets.nexperia.com/documents/data-sheet/BAV199.pdf), verified through the web document reader. Direct PDF download returned HTTP 403; this is not a complete PDF extraction.

BAV199,215 is a SOT23 series-connected low-leakage diode pair. Pin 1 is A1, pin 2 is K2, pin 3 is K1/A2. We use pin 1 at GND, pin 2 at +5V_ADC, and pin 3 at the protected AUX node. Manufacturer identifies low-leakage applications and typical switching time of 0.8µs. This part is not being represented as a qualified cable surge suppressor.
