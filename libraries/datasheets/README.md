# Datasheet library

Original supplier/manufacturer PDFs and searchable, page-numbered Markdown extractions.
PDF drawings and tables remain authoritative; text extraction may lose symbols or layout.
This folder includes historical parts: presence here does not imply a part is fitted.

Regenerate with `python3 tools/datasheets/extract.py` (requires Poppler `pdftotext`).
